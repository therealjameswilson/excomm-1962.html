# Public Domain Portrait Overrides

Drop portrait files here to override the default ExComm figure photos:

- `mcgeorge-bundy.jpg`
- `robert-mcnamara.jpg`
- `john-f-kennedy.jpg`
- `adlai-stevenson.jpg`
- `dean-rusk.jpg`

If a local file is missing, the game falls back to the prior Wikimedia portrait URL.
